# Firebase Studio

A full-stack, responsive web application built with **Next.js** and integrated with **Firebase** backend services, deployed seamlessly on **Vercel**.

---

## 🚀 Live Demo

- **Live URL:** [https://vermaexpensesco.vercel.app/](https://vermaexpensesco.vercel.app/)
- **Repository:** [https://github.com/HarshDev-X/studio](https://github.com/HarshDev-X/studio)

---

## ✨ Features

- **User Authentication:** Secure sign-in/sign-up powered by Firebase Auth.
- **Expense Tracking & Analytics:** Real-time data management for personal/business financial tracking.
- **Dynamic Frontend:** Built with Next.js App Router for optimal rendering performance and fast load times.
- **Database Integration:** Cloud storage and database management powered by Firebase Firestore.
- **Responsive UI:** Modern, mobile-first design styled with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (React)
- **Language:** TypeScript / JavaScript
- **Styling:** Tailwind CSS / PostCSS
- **Backend / Database:** Firebase
- **Deployment:** Vercel
