# **App Name**: ExpenseWise

## Core Features:

- User Authentication: Secure user registration and login using JWT.
- Transaction Management: Add, edit, and delete income and expense transactions with categories including 'Hostel'.
- Currency Handling: Default currency set to Indian Rupees (INR) with all amounts displayed with the ₹ symbol.
- Automated Calculations: Automatically calculate total income, total expenses, and remaining balance.
- Dashboard Overview: Display key financial metrics such as total income, expenses, and balance.
- Data Visualization: Generate charts (monthly bar, category pie, line chart) to visualize spending patterns.
- Transaction Summarization Tool: Generative AI tool to provide summaries of user spending habits and potential saving areas based on entered transactions.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for trustworthiness and financial stability.
- Background color: Light blue-gray (#E8EAF6) for a calm, modern feel.
- Accent color: Vibrant orange (#FF9800) for call-to-actions and highlights.
- Body text: 'PT Sans', a humanist sans-serif with a modern, slightly warm feel, for body text.
- Headline font: 'Space Grotesk', a geometric sans-serif with a computerized, techy, scientific feel, for headlines.
- Use clean, minimalist icons to represent transaction categories and financial indicators.
- Mobile-first responsive design with a sidebar navigation for easy access to different sections.
- Smooth transitions and subtle animations for user interactions to enhance the overall experience.
